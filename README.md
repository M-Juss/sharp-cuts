# Sharp Cuts

A multi-branch centralized barbershop management system designed to streamline operations, bookings, and performance tracking across all branches.

## Overview

**Sharp Cuts** is a full-stack system built to manage barbershop franchises in a centralized and scalable way. It allows customers to easily book appointments while giving business owners and staff the tools to manage operations, monitor performance, and handle bookings efficiently.

The system supports multiple user roles, each with specific responsibilities, ensuring smooth coordination between branches and a seamless experience for customers.

## User Roles & Features

### 🧑‍💼 Branch Owner

* 📊 View and track performance of all branches
* 🏢 Manage franchise branches (add/remove based on contracts)
* 📈 Monitor overall business analytics
* ⚙️ Maintain centralized control over the system

The Branch Owner has full visibility and control over the entire franchise ecosystem.

---

### 🏪 Branch Franchisee

* 📊 Track individual branch performance
* ✂️ Manage services offered in the branch
* 👨‍🔧 Add or manage barbers
* 👥 Assign branch admins (front desk staff)
* 📅 Accept or decline customer bookings

Franchisees handle the day-to-day operations of their specific branch.

---

### 🧾 Branch Admin (Front Desk)

* 📅 Assist in managing appointments
* ✅ Accept or ❌ decline bookings
* 🧑‍🤝‍🧑 Coordinate with customers and barbers

Branch Admins act as the front desk personnel, ensuring smooth scheduling and customer service within the branch.

---

### 💇 Customer

* 🏪 Browse available branches
* ✂️ Select desired services
* 👨‍🔧 Choose preferred barber
* 📅 Pick date and time for appointments
* 📖 Manage and view bookings

Customers can easily book appointments tailored to their preferences across any available branch.

## Key Features

* 📍 Multi-branch booking system

* 👥 Role-based access control
* 📊 Branch and franchise performance tracking
* ✂️ Service and barber management
* 🔄 Centralized system for all branches

## Tech Stack

### Frontend

* React (TypeScript)
* Tailwind CSS

Provides a modern, responsive, and user-friendly interface for all user roles.

### Backend

* PHP

Handles business logic, data processing, and API communication for the system.

## How It Works

Customers select a branch, choose a service, pick a barber, and schedule an appointment based on availability. These bookings are then managed by Branch Admins and Franchisees, who can approve or decline requests.

All branch data is centralized, allowing the Branch Owner to monitor performance and manage the entire franchise system from a single platform.

## Purpose

This project was built to:

* Simplify appointment booking for barbershops
* Centralize management of multiple branches
* Improve operational efficiency across franchises
* Provide insights into branch performance
* Practice building a role-based, real-world business system
